# CyberSand Workbench Windows evaluation

**Draft / HOLD**. The package manifest identifies the exact application source, Godot, native and Rapier runtimes. Extract the whole ZIP to a short, writable folder before running it.

1. Open **Open Workbench.cmd** to try the integrated candidate. Use **Open Baseline Workbench.cmd** for full material publication and original presentation with the same application and simulation sources. Both use the evaluation folder's interactive save profile. Compare the same saved World and settings in fresh processes.
2. Fly Needle quickly and turn sharply near dense terrain. Try Free and Follow, zoom and pan, body impacts, material edits, Fire and Water, pause and resume, then save and reopen. Try one and four native workers, and record any freeze with its exact setting and action.
3. Close other CyberSand windows and run **Test It.cmd**. The ordinary campaign runs the original 2048-square dense/sparse transition sequence and real Needle Free and Follow with one and four requested workers in fresh A–B–B–A processes. **Run Diagnostic.cmd** runs just the one-worker Follow case. The optional `Test It.cmd -Extended` adds four-Water-family, delayed-ACK and slow-native comparisons.
4. Inspect `Test-It-Results` and fill in this file. **Pack Results.cmd** includes the latest run's raw data, original screenshots, logs, source identity and these notes in one ZIP. Automated capture completion and physical acceptance are separate fields.
