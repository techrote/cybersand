# A useful route through the candidate

Start with the [root README](../../../../README.md) for the product and gallery,
then use the [documentation portal](../../../README.md) to choose a task. A first
hands-on reading is **Getting started → First Workbench session → Painting and
history → Saving authored worlds**. Art, generation, Water, materials and actors
then have their own practical routes. The table below is review navigation;
its linked pages remain the canonical instructions.
