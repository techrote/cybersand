## Source-backed behavior and successor scope

**Current production:** `physical_usable_runtime.gd` `physical_snapshot` adds
copied metered-owner context to every physical actor row, including ordinary
equipment. Main's `refresh_actor_usables` delivers that readback through
`physical_actor_session.gd` `accept_equipment_feedback` and
`physical_usable_equipment.gd` `accept_readback`. A newly created actor starts
without a copied context. Metered activation then refuses with
`awaiting_native_owner_context`; context arrival cannot manufacture a selected
metered profile or replenish native stock. No production correction is made.

**Current local test source:**
[the transaction fixture](../../godot/tests/test_liquid_physical_transaction.gd)
uses a bounded initial readiness interval before capturing equipment bytes.
[Its test-local copied-value helper](../../godot/tests/support/physical_retention_readback.gd)
requires delivered readback matching current actor/equipment/body and control
identity, the accepted receipt's actual `session_generation` and full
`policy_hash`, publication freshness, valid complete context and exact ledgers.
It reads pure `_view(0, false)` and copied publication values; it neither calls a
native World nor delivers feedback or advances simulation time. The receipt
keys are emitted by `cyber_prepared_liquid_world.hpp`; no guessed
`native_generation` receipt field or pending candidate generation is used.

Production `accept_readback` checks control generation strictly at delivery.
A later cancellation can advance Main's live control generation without
invalidating the already copied native context. The readiness helper pins the
minimum accepted control generation, requires the live view to equal the current
Main frame, and allows the retained publication generation only within that
accepted-to-current interval. Preaccepted and future publications still fail.
Native generation and full policy hash remain strictly receipt-bound; neither
is replaced by a control-generation counter. Readiness observes a retained cache
rather than forcing an old publication to become synchronously deliverable again.

During initial settling, graph/space, paused pose, canonical native receipt,
host observation and noncontext equipment/resource values remain guarded. An
already-populated early context is retained exactly. Missing readback causes a
watchdog-bounded test failure rather than an empty-context fallback. Once ready,
the entire equipment value is serialized and all six original terminal
retention predicates remain, including all copied metered fields. Additional
submission/pending-boundary checks retain the first observed difference instead
of waiting for a later repair to hide it.
