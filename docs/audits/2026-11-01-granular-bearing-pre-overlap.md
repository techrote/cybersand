through APIs named local: [pinned physics_world.rs](https://github.com/appsinacup/godot-rapier-physics/blob/172c66f5a88bf1164c2b8cf2d775ed889edefd75/src/rapier_wrapper/physics_world.rs#L379)

Earlier `rotated_normal` values double rotated the raw normal. Those acquired
bytes remain preserved but this derived field is disqualified from interpretation.
The corrected observer retains raw world normal/position. Built-in contact impulse
is the normal component; the [pinned extra API](https://github.com/appsinacup/godot-rapier-physics/blob/172c66f5a88bf1164c2b8cf2d775ed889edefd75/src/servers/rapier_physics_server_extra.rs#L128)

An initial supplemental run assumed all were vectors; script errors caused the
runner to reject that run despite unchanged physical rows. Typed Variant readback
then passes. Both failures and original source/runtime hashes are retained in the
