Specialist B independently refreshed the Actions metadata, rehashed the original
Linux ZIP and checked every original member CRC: 928 members. B then executed
the unchanged independently authored
[native original-byte verifier](https://github.com/techrote/cybersand/blob/06a3ab765255c72d80e8e0866beae1ba725f9880/tools/ci/verify_art_creative_native_evidence.py)

64292c1a48babae89b51e0dfa2c99792c29e9f2f813962294da8fc6d8c4536a9.

The verifier decodes the original diagnostic PNG material bytes, checks their
plane hashes and PNG CRCs, then replays every original native before/after cell
tuple and receipt source chain. It checks acknowledged counts, source 0/58
eligibility, bounded chunks, predicted stage boundaries, final planes and the
translated direct controls. It imports no Art rasterizer or fixture generator,
runs no native application and makes no model request. Rendered framebuffers and
saved Setup files are checksum-bound; their visual interpretation and actual
reopen executions remain separate evidence scopes.

The derived [comparison script](delivery-native-3a/reconcile_delivery_native.py)
then checks the original source, runtime and all scene/preview/protection/native
endpoints against bcc. Its Linux execution passed **445 checks, zero failures**.
These are evidence reconciliation checks, not additional application tests.
Complete derived outputs are in [delivery-native-3a](delivery-native-3a).
