## Native authority trace

The coordinator never treats provider prose as execution approval. Discuss and
Review only retain the response in the current-session conversation. Propose
and Develop parse and compile a bounded typed proposal and start a copied-value
preview. An explicit next-stage approval is the only coordinator path to
`ArtBatchExecutor.submit_guarded`.

The executor retains the ordinary direct implementation and native history
owner. Guarded stages supply the captured source identity, destructive permission
and conservative cell budget. Each bounded native chunk carries that source.
The executor advances the next source only from an actual native receipt.

The simulation worker checks source identity at queue admission and again on its
exclusive World owner immediately before applying a chunk. Protected rectangles,
World bounds, rigid-body masks and the existing source-material policy remain
enforced by the actual write path. Source Empty (0) and Hard Wall (58) are the
only ordinary Art overwrite sources. No replacement mutation engine or native
C++ authority was introduced in the reviewed changes.

PAINT supplies native observation through its own capture slot and a scoped
completion callback. It gives Art copied materials and native identities; Art
does not take a live World reference or consume PAINT's receipt mailbox.
Cancellation identifies the specific capture operation. Post-stage verification
compares the entire observed material region against the preview hash and checks
the native changed-cell total. A partial or inconsistent result remains an
acknowledged prefix and makes continuation stale.

## Context and product scope

The context distinguishes stored materials from rendered canvas appearance and
limits native capture to 262144 cells. Model context is bounded separately from
the private captured plane. The inspector shows selected data, omissions,
source identity, constraints and provenance; it discloses the parent proposal
and recent host receipts used by Develop and Review. External admission binds
authorization to the inspected source/options/provider/endpoint disclosure.

Conversation memory is a bounded projection of the current session. Complete
admitted originals and redacted audit records remain separate. No historical
conversation, World reference or old execution approval is restored in the
reviewed session coordinator. Existing direct authoring remains available;
the new cross-mode guard must also preserve a pending direct run's ownership.

The new UI has no provider or native executor instance. Its signals ask the
host for context, request admission, preview, stage approval, cancellation and
focus selection. Historical proposals cannot acquire approval through their
view. Copy is data export only.

## Creative evidence limits

The native campaign calls actual ordinary Workbench capture, existing native
executor, native material readback, ordinary Setup save/reopen and displayed
framebuffer capture. Its nine staged examples and nine direct controls use
deterministic known packets. The complete preview is checked for zero writes,
protected cells are compared, and final native planes are checked against
predicted hashes. Selected clear rectangles are checked Empty; this is not
an actor traversal, physics stability or structural load-bearing proof.

Fixed-proposal knowledge ablation deliberately retains geometry. Identical
geometry does not prove that retrieval improves a real model's decisions.
The 24-brief fixture cohort's held-out labels belong only to a later genuine
owner-operated model evaluation; known fixture mappings establish no model
generalization. Refusals and failed experiments must remain in the decision
packet. The [native independent review and owner-model protocol](NATIVE-INDEPENDENT-REVIEW.md)
defines the separate creative evaluation.
