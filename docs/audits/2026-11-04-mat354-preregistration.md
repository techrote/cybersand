## Measurement definitions

The apparatus compiles the unchanged production `world.cpp` exactly once by
including it from a standalone native test translation unit, with the ordinary
supporting production sources. The existing `PrecisionProbe` friend supplies
copied, const, between-tick observations only: block active/quiet/due metadata,
resident usage and complete stored-state observations. It does not call mutation,
kernel or scheduler helpers and does not expose live pointers. No private-access
macro, production hook, source rewrite or shadow-catalogue consumer is used.

Existing TickStats records actual selected visits, jobs, per-phase jobs, maximum
distinct claimants in one dispatch, moves, allocations and active blocks. A
selected visit is not a kernel call when a body mask rejects the source. Existing
source-specific PhysicsTotals provide per-tick (not cumulative-summed) downward
rejections, lateral probes, moves, conversions, block wakes/sleeps and overflow.
For stationary nonreactive generic/MoltenGlass sources, downward-rejection
triples (or the central downward rejection alone) identify actual flow execution. Conversion can bypass flow and is
recorded separately. Mixed reactive controls do not invent per-cell visits.
The counters are whole-World subject-material totals. Only singleton fixtures
bind that total to the traced source; pool/distributed rows retain aggregate
scope. RNG-reference values are potential draws, with explicit applicability;
they do not imply a kernel consumed a draw after an earlier conversion/refusal.

Record exact stored material/a/b/temperature, source location, thermal phase and
due opportunity, independently calculated mobility byte/threshold, legal side,
known external wake cause, block deadline before/after and final outcomes. A
sleeping block can still be scanned because another block selected its whole
core; never infer omission from `active=false` alone. Record first/last actual
execution and first movement/conversion. Finite horizons cannot prove absence
for all future time without an explicit source-derived closed-state argument.

At every completed step independently census the bounded fixture domains and
compare their material counts and Water quantity to the native ledger. Retain
source/sink kinds and conversions, not a fictitious conserved chemical mass.
Independently conserve species counts (MoltenGlass+Glass, Cement+Concrete and
Ice+Water conversion groups), allowing only named external edits. Closed Water
controls conserve exact quantity, not the number of fractional carriers.
Worker/repeat comparisons use exact per-step physical-state identity at matching
configuration; quiet3/1024 comparisons use stored physical tuples rather than
requiring scheduling-inclusive hashes to match. Time only `World::tick`, with
external observation/census/reduction cost excluded. The enabled native
histogram's in-tick cost remains included; no timing neutrality is claimed. Report
descriptive work and idle costs, not a controlled benchmark or counterfactual
deadline-fix overhead. No future fix is executed in Phase A.

## Bounds, failures and platform claims

campaign has a1800-second bound. Outputs are streaming finite JSONL. Stop a case,
retain its partial output/error and fail qualification on World quarantine,
accounting mismatch, unexpected product, source identity mismatch, sanitizer

cases as passes. An apparatus correction gets a new committed identity and a
new run directory; the original evidence remains.

CPU, compiler/version/flags, dependency inventory, Git commit/tree, executable
hash, argv, completion and raw-output hashes for every executed build/case.

## Apparatus correction registered after the first campaign

The first compiled apparatus is local checkpoint `23ca8074`. Its original
registration and implementation remain in Git history. Independent review found
that the busy control supplied Smoke only in the source's initial core. A generic
liquid could move across a core seam and then lose continuous active coverage.
The revised construction supplies Smoke in every core intersecting a reachable
interior Empty destination as well. This changes only the control apparatus;
all552 case identities, horizons, decision criteria and production bytes remain
fixed. The earlier finite-coverage observations retain that limit. A fresh
committed source and campaign must qualify the corrected control; earlier runs
are not relabelled.

The first ordinary run also has one retained raw-identity failure (a truncated
distributed-Paste output); its receipt's execution success is not qualification.
A subsequent identical-source run stopped on an artifact executable-mode loss,
and the first ASan/UBSan process failed at LeakSanitizer's inaccessible process
inspection. Preserve all three attempts. Any explicitly leak-disabled run must
report only address/undefined-behavior coverage, not LeakSanitizer acceptance.
