## Product behavior and architectural ownership

The ordinary Architecture panel now offers **Prepare Art proposal…** and
**Configure Art…**. Preparation uses the existing lazily created Art provider and
captures the current typed Architecture request without sending it. A disclosure
dialog identifies the selected provider, endpoint, model, limits, instructions
and complete typed request; **Send disclosed request** authorizes that captured
request. Opening Architecture alone creates neither Art nor the new mount.

One existing Art provider owns credentials, HTTP, asynchronous value preparation,
audit and response completion. The mount registers an owned callback instead of
adding another `finished` listener. It fences the exact provider instance/serial,
configuration and credential revision, visible intent, every copied request
value, World/worker generation, native observation/history identity and current
StageSession. A changed identity retires the owned request. Ordinary Art Hide
continues ordinary requests, while Architecture Stop retires only Architecture's
request. An occupied ordinary Art provider refuses proposal admission without
cancelling the ordinary request.

Typed proposals never write native material. Architecture retains proposal
adoption, stage preview, fresh approval, bounded execution, receipts and ordinary
Undo. No automatic model call, experimental startup activation, new native World,
worker, movement authority or history implementation was added.

The production regression exercises the actual mounted panels over an ordinary
512-square native World. Two deterministic loopback sockets establish actual
transport and cancellation. Three explicitly approved stages change 4,120, 488
and 12 native cells; their exact material-plane results agree with host receipts.
Three ordinary Undo actions restore the complete original capture. Zero ordinary
provider completions receive an Architecture response. Model/credential changes,
StageSession replacement, New Canvas, stale disclosure and changed request values
are refused through the real host path. These are engineering observations, not
genuine-model creative or physical owner acceptance.
