## Source and package contract

and its ledger PR rather than another permanent Draft branch. Only a push

no invented product identity. Lead fills the exact accepted-main commit/tree

source-derived execution budget. The product source must contain the promoted

different identities and both appear in the manifest and final receipt.

accepted source. It preserves original source, Godot, native, Rapier and portable
VC custody. The adapter checks the actual engine and dependency bytes against
the existing accepted pins, verifies every one of the unchanged 105 native and

runtime binary to the source checkout. No new native build is claimed.

The ordinary Workbench command uses the established ordinary launcher arguments
and portable user-data arrangement. Canonical generator profiles are staged by
the existing accepted helper, preserving `examples/worldgen`; all five authored
AMBIENT examples and their owner guide are included. The original Goblin
manifest and PowerShell launcher remain unchanged inside the common payload.
An outer manifest records every original and added byte. Both top-level CMD
launchers use that same application and source-matched runtime.
