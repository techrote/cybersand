## Why the historical jobs should remain separate

The existing Goblin `windows-developer-evaluator` has a 55-minute parent. Its ten
canonical calls alone reserve ten 240-second imports and thirteen 300-second
child cases: **6,300 seconds**, before cleanup, six actual campaigns/replay,
dependency acquisition, reproduction and extracted-package qualification. Its
historical completed observations remain evidence, but this parent cannot
truthfully be extended by appending storage tests.

The existing Art Windows job has a 120-minute parent and runs both headless and
displayed collaborative gates, broader final-workbench groups and packaging.
Each collaborative invocation contains eight 600-second cases and one
1,800-second native case. Two invocations already reserve 13,200 seconds before
the other work. Appending the new storage matrix does not solve that accounting.
This note does not change the original jobs, watchdogs or accepted evidence.
