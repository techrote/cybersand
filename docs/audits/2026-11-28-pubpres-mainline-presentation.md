## Selected architecture and bounded retained presentation

The production changes preserve Stock Safe, Full two-slot publication,
Water-compatible composition, all-worker native completion, the current native
and Rapier owners, and accepted-frame actor picking. No alternative publication
or renderer treatment was made the default.

The retained-endpoint repair addresses a specific gap: a newer material image
can become available before the current native actor response. The old material
certificate then becomes stale even though the previously submitted physical
endpoint may remain admissible. `_revalidated_submitted_water_hold` in
`godot/scripts/main.gd` rechecks that already submitted endpoint against the
actual current and active previous images. It does not select a new pose or
manufacture a new native/physical completion.

The helper retains all of these fences:

- Exact bridge, session, epoch, member identity, generation and body RID.
- Same native World generation, unchanged physical geometry and the exact
  endpoint already present in the submitted frame.
- The original physical step, native tick/sample, native completion time and
  physical completion time. A separate material-revalidation field describes
  the newer visible image identity.
- The resolver's existing shared scan/time allowance and nonrenewable 100 ms
  hold clock. Rechecking an endpoint cannot restart the clock.
- Refusal for unavailable previous history, changed ownership or geometry,
  newly blocking material, exhausted allowance, prior withholding or contact
  clipping. No weakening of the contact policy was adopted.

Specialists A and C independently reviewed the implementation and its refusal
cases. The existing broad Water fixture gained observation of revalidated held
proofs and original clock/pose continuity; its actor population, world, movement,
history-turnover stress, timing allowances and completion thresholds were
preserved.

The separate mounted witness
`godot/tests/test_workbench_retained_water_hold_native.gd` uses ordinary authored
installation and real manual Steps. Exactly one resolver call cannot obtain its
newest native proof. The first post-draw observation must retain the original
endpoint, original native fields and original physical step. A second probe
explicitly supplies an expired original hold clock and must refuse it. Ordinary
mouse input selects the accepted Barrel pose. Only after the first real draw
does the observer briefly freeze processing for hidden/restored pixel controls.
The ordinary runtime then resumes.

This is a controlled missing-response witness. It does not establish the
scheduler cause of the historical omission, general visibility through opaque
material, or physical monitor presentation.
