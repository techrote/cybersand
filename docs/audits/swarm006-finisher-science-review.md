intact. No accepted/Apply-authorized material digest mismatch was found. A safe
outer refusal does not excuse contradictory rejected-history evidence, so the

The successor correction reserves the existing bounded diagnostic-finalization
cost, `12*n + 64*instances + 32*ports`, before material mutation. Search debits
cannot consume that reservation. An actual finalization spends the same
formula's cost once, and sets the nested status and termination before producing
the digest. A proposal that cannot afford the reservation refuses explicitly
before mutation. Withdrawal keeps enough reserved capacity for the prior or
proposed footprint until the operation has finished. Releasing unused reserved
capacity does not refund consumed work.

The reviewed change preserves resource ceilings, finite grammar, candidate
ordering, and default options. It changes where some low-budget attempts stop.
Any endpoint, work, or parity effects must be measured and reported on the
successor. This is a correctness and accounting correction on a revealed
corpus, not a new registered unseen experiment or a holdout retuning.

The original diagnostic-granularity finding remains separate and PARTIAL:
compound territory/protected/context reasons, combined span occupancy/ownership/
protection reasons, and territory/reservation fallback are not made granular
by this digest repair. The bounded finite catalogue cannot establish global
infeasibility. See the retained
[diagnostic review](https://github.com/techrote/cybersand/issues/704#issuecomment-7063144002).
