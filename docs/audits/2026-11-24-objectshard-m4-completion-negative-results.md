## Acceptance boundary

The owner's earlier below-10-FPS observation remains a physical Windows/NVIDIA
acceptance question. A cloud software-renderer run can establish actual
renderer submissions and coherent pixels, but cannot establish physical
monitor presentation, driver behaviour or owner playfeel. Runtime custody,
native progression, render submission and physical owner acceptance must stay
separate in the final decision.

No result in this record authorizes a merge, Ready promotion, production
runtime publication or default activation.
