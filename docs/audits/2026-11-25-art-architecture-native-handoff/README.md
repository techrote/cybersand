## Purpose and explicit host mount

The stable Art contract is owner-installed
`ArtProposalTransport.bind_owner(existing_art_panel.provider, configuration_snapshot, live_guard)`.
The Architecture bridge receives `dispatch(request, completion, pre_dispatch_guard)`
and scoped cancellation. The principal Art UI does **not** already expose a mounted
Architecture dispatch control or a public settings factory. This experiment owns
the small explicit host mount: it reads settings and the synthetic key from the
one actual ordinary Art panel, captures its World epoch, supplies a live native
inspection guard and routes the proposal-only completion to the unchanged bridge.
No second Provider, credential store, completion-to-paint listener or model path is
created. The remaining production host mount belongs to a later coordinated
integration decision; this fixture must not be described as an already-shipped UI.
