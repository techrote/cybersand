## Chosen integration contracts

The existing Workbench owns the sole Play World, worker, camera and Rapier session.
The existing layer owner retains three paused native decorative Worlds. Import and
construction use copied material observations and the existing paint executor;
Play operations pass through the ordinary paint editor, which remains the sole
consumer of its worker receipts. No live Play reference enters a new subsystem.

`CYSSTRAT` v1 remains readable and writable with its exact fields and meaning.
V2 adds strict authored `atmosphere` and `authoring` metadata; an explicit lossless
upgrade supplies disabled empty defaults. Save records authored layouts and
settings, not evolved physical continuation or transient visual phase.

Raster placement uses a bounded zero-write proposal with source/mask/mapping
digests, deterministic pixel-grid sampling and explicit native approval. Alpha
defaults to no-write; actual Empty writes require replacement/clear policy.
Native modules retain exact material IDs and permitted orthogonal transforms.
Plans execute at most 4096 cells per chunk, with fresh owner/revision/permission
and actual material preconditions. A stopped prefix is an explicit partial
result, never a cross-plane transaction. Publication failure cannot undo a
confirmed native commit or label it uncommitted.

Atmosphere is a visual CanvasItem child of the existing decorative drawable,
using its coordinates, clipping, parallax and opacity. Up to twelve regions and
384 deterministic motifs create no native World, material mutation, texture
publication or physics. Visibility/pause freezes the visual phase; callback
contributions are bounded to 0.1 seconds and do not catch up after a stall.

Alternative considered: running decorative native clocks. This remains gated
on matched measurements; presentation-only motion is the useful default. No
dynamic-native capability will be claimed from visual smoke, rain or light.
