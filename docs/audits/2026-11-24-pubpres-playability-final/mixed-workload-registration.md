## What the responsiveness observations mean

The first matching current CPU material image after a real production upload is
recorded for each paint. It retains the action, pixel, World, revision, upload
serial, material native tick, material generation clock and observation clock.
Stationary materials and erase require the exact painted center; moving Sand
uses a registered 33-by-81-pixel search. Every attempted search, including a
failed search, contributes to the disclosed count, total elapsed time and
maximum attempt time. The instrumented Main callback includes these costs.

This is a source-image publication witness. It is not GPU completion or
physical scanout. Existing supplementary timing also reports first command
admission to genuine completion and the age of the latest completed physics
state at delivered draw notifications; it does not assert displayed-pose truth.
Final actual GPU bytes must still match the current source CPU image, and the
runner requires the independent source-exact graphical history qualification
to pass first.

Tick-addressed painting enters an asynchronously owned native worker queue. A
worker can already be executing the next prerequisite when Main queues a brush.
Therefore equal requested physical tick does not guarantee equal native
application tick across runs. Actual material tick/revision witnesses are
retained. The runner calls these single sustained qualification captures and
does not compare them as an equal material timeline or declare a speed winner.
