## Native semantics and source-pinned before/after proof

`contact_cell_available()` is a read-only availability witness. It refuses failed
Worlds, coordinates outside the declared billion-cell bound, absent chunks,
unapplied simulation-region changes and cells outside selected cores. It does not
manufacture residency, reinterpret unknown storage as Empty or write a material.

The remaining World additions impose a new transaction policy. Prepared,
Acknowledged, Committed, Restored and Quarantined phases fence mutation; Disabled,
Idle and Active do not. Throwing entry points include direct material/temperature
writes, painting, reservation, region changes, transient-field configure/clear,
generated-chunk installation and tick. State writes, obstacle writes, relocation
and queued explosions return false while fenced. Player-field application returns
its default `InvalidCommand` result. Adhesion's void setter silently returns.
`clear()` explicitly retires SOL ownership during the ordinary destructive World
reset. These are observable return/error policies, not byte-identical legacy
semantics in every phase.

The pressure include refuses physical hashing, both liquid comparison projections
and CYPS save whenever the SOL store exists in a non-Idle phase. That refusal is
necessary to avoid pretending that omitted aggregate state is a complete save or
physical identity. It also applies while Restored awaits its collision receipt.
Legacy `state_hash()` and `content_hash()` retain their historical limited domains.
They are not substitutes for an unavailable full physical hash.

The [independent C++ probe](../../tools/material_catalogue/probes/mat_sol_legacy_probe.cpp)
was compiled separately against accepted main and exact SOL source. It exercises
all 131 valid material IDs in bounded rooms over 12 ticks, translated/core-offset
placements, mixed native Sand/Water/Salt neighbours, temperature writes, and four
liquid family profiles over 20 ticks with transient masks and region exclusion/
re-entry. It records exact native content/state/physical/projection hashes, save
SHA-256/size, restored physical hash, Water quantity, active/resident chunks and
terrain revision. Every saved byte stream round-trips exactly. Active host-owned
masks are recorded explicitly: they enter physical hashes but are intentionally
absent from CYPS, so an un-reinstalled mask is not called a restored host state.

## Reproduced Godot boundary defects

The [Godot probe](../../tools/material_catalogue/probes/mat_sol_godot_boundary_probe.gd)
constructs the actual 520 native members and six proxies, reads back every phase,
and exercises public GDExtension methods in watchdog-controlled child processes.
Reservation/finalization receipts are synthetic and source/shape-bound. This
isolates the actual native facade without claiming a live Rapier body or physical
clearance. Every causal abort has successful fixture checks and a `BEFORE_CALL`
marker; its `AFTER_CALL` marker is absent.

### Physical and comparison hashes abort instead of refusing safely

At the pinned source, `CyberNativeCellWorld::get_physical_state_hash()` invokes
the newly throwing World method without catching its exception. The two valid
`get_liquid_comparison_hash(1/2)` calls have the same problem in
`pressure_optimization_inspection.inc`. All three abort actual Linux Godot with
SIGABRT/exit-6 in Prepared, Acknowledged, Committed, Restored and Active, at both
configured worker counts: **30 process aborts**. The diagnostic is
`solid aggregate/transaction is not serializable in CYPS2/3`.

Disabled, Idle, cancelled, completed rollback and reset controls all return
normally. `CyberDemoBridge::export_physical_state()` already catches the native
exception and returns empty bytes plus its diagnostic safely in all ten tested
non-Idle phase/worker combinations. Correctly invoked `diagnostic_snapshot()`
remains callable; its legacy state hash is not a physical serialization proof.

### Simulation-window mutation also lets the exception escape

`set_simulation_window_enabled(true)` updates facade state and calls
`refresh_simulation_region()`, which reaches the newly fenced World region setter
without a catch. Prepared, Acknowledged, Committed and Restored each abort at both
worker counts: **eight further process aborts**. Idle and Active controls return.
The failure is the native mutation/tick fence, not the physical-hash exception.
The neighbouring `set_simulation_window(...)` route reaches the same uncaught
helper and needs explicit source review during repair; this experiment executes
the enabled setter, not every helper caller.

### Adhesion readback disagrees with native authority

The facade caches a requested adhesion value before calling World. During its
fenced phases, World silently refuses the change, while the facade getter reports
the new value. For each of Prepared, Acknowledged, Committed and Restored, at both
worker counts, this probe requests false from a true initial state, observes
facade false, safely cancels or completes rollback, exports native CYPS, imports
it into a different adapter and reads **true**. All **eight** such cases have
`matches_authority=false`. Both Idle controls request false and read false after
the same native round trip. No native getter, serialized bit or expected value
is fabricated from the facade cache.

## Smallest required repair and later integration sequence

The owning SOL implementation needs a bounded, independently reviewed facade
repair. Preserve native mutation/serialization refusal. Convert every affected
public boundary into a safe, explicit refusal that callers distinguish from a
valid hash/save/applied request. Cover both physical and liquid hash accessors,
all simulation-region facade routes and the adhesion cache/authoritative readback.
Do not fabricate a fallback hash, silently serialize omitted aggregate state,
weaken the native fence or report cached intent as applied state.

After that repair, rerun the phase matrix against fresh matching Linux/Windows
runtimes, including workers 1/4, failed/rollback/reset paths and actual host
ownership. Requalify unchanged non-SOL material/policy/query/persistence oracles,
native GCC/MSVC and sanitizer checks. Existing passed native tests did not
exercise these exception boundaries; repeating them alone will not close the
new blocker.

Only after successful independent review may a separate source-scoped two-receipt
transition be designed. One receipt authenticates frozen A-only source/lock
against `0fd4af59`; another must bind the explicitly reviewed SOL source/tree,
all 27 path/role identities, the exact two complete changed blobs, catalogue/
capability identities, included executable dependencies and reviewed semantics.
Unknown source, missing history, changed baseline, altered roles/paths, shadow
imports, stale runtime inputs or an editable manifest which supplies its own
authority must fail closed. Direct original `compatibility.py --check` must
continue rejecting SOL bytes. No default main route, skip, ignore-list or
automatic hash refresh is justified by this investigation.
