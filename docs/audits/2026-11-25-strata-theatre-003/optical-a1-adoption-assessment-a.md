# A1 adoption assessment — deferred source-bound follow-up

Date: 26 November 2026. Rendering review by Specialist A.

**Recommendation: retain A1 as a justified candidate for a new, explicitly
qualified application revision. Do not substitute it into the current owner
package. The principal delivery remains fd0830ab with PERFORMANCE HOLD.**
The lead chose to finish that complete portable delivery rather than restart
the programme late. This document describes the concrete follow-up boundary;
it does not implement, publish, merge or activate a new application.

## Evidence supporting the candidate

The sole candidate change skips downstream optical work when both centre and
already-filtered neighbourhood alpha are exactly zero. It retains the filter,
all nonzero coverage, final blend, uniforms, materials, texture ownership and
native behavior. The source argument and B's independent algebra review support
exact output for the current modules. A future module that creates coverage
independently of those samples would invalidate that argument.

The corrected v2 experiment used two actual hosted backends with the same frozen
application. On each host, original and candidate passed 109 renderer assertions
and 18 exact decoded PNG comparisons. Six native-world pairs also matched
exactly per host; live cached/drawable attachments, source snapshots, native
hashes and retirement were verified. All twelve same-repeat profile comparisons
improved both actual physical rate measures. Full evidence remains in the
[Linux review](optical-a1-v2-linux-review-a.md) and
[Windows/two-host review](optical-a1-v2-windows-review-a.md).

Those results support taking A1 into a new application revision. They do not
prove every scene or profile meets the performance criterion. A1 Gameplay
Clarity reached 90.466258% of Classic on Linux and 90.195292% on Windows, with
physical p95 inside the registered allowance. Architectural reached 89.682079%
on Linux and 90.752856% on Windows; its Linux rate still fails. Windows initial
challenge admission remained 63.802 seconds against 45 seconds.

## Exact proposed implementation boundary

Use the qualified Strata ancestry and a new recoverable source checkpoint.
The only production-source delta should be
`godot/shaders/strata_optical_plane.gdshader`, changing the original SHA256
`b64c8fe105fb981b56aab38f44cfca2f875ea975792593c11dd9692892a0e8eb` to the
already tested A1 bytes
`50518cda2c8b9635d4b15b71ade65752fa9f859f447624940c9705acf814995f`.
An allowlisted byte comparison should establish that all other application
sources, original/new scene geometry, profile definitions, native inputs and
assets are unchanged. Qualification requests and documentation may receive their
own explicit changes; they are not hidden application behavior changes.

Do not combine the proposal with texel-fetch changes, new filters, palette
retuning, altered profile strength, startup work, scheduler work or native
publication experiments. Do not add an in-application runtime override switch.
The ordinary installed shader must be A1, with a new application commit/tree,
new package manifest and new artifact identity. Preserve the fd0830ab package,
receipts and negative results as the comparison checkpoint.

The existing Godot, native and Rapier binaries may remain the same qualified
bytes where all relevant source/dependency inputs match their provenance.
There is no reason to rebuild native C++ solely because this shader changes.
The new application source identity must nevertheless remain distinct from the
native build revision and from both the old application and external observer.

## Nominating Gameplay Clarity without changing defaults

Gameplay Clarity at Balanced is the supported engineering nomination for the
next revision because it met the registered numeric rate and tail limits on
both research hosts and had the strongest independent physical-route scores in
the existing challenge review. It remains an editable artistic option. This
nomination does not automatically enable optics for old scenes, change the
Classic fallback or override the owner's preference for richer architecture.

Record the nomination as a prospective test case and retain the exact original
profile parameters. Do not reduce clarity strength, change geometry or substitute
a less demanding camera after seeing a miss. Keep Architectural's Linux failure,
the three-repeat populations and the narrow 0.195292-point Windows margin in the
decision packet. A repeated miss is still a miss; the 90% requirement and physical
p95 rule are not softened. The 45-second admission target remains independent.

If the nominated profile passes the new application gates, the valid statement
is acceptance for that exact revision and registered hosted workload. It does
not automatically establish headroom on every scene, quality tier or device.
Physical Windows 11/NVIDIA acceptance, owner artistic acceptance and unprimed
human readability remain separate. Optional cinematic modes can retain explicit
cost limits without being described as balanced gameplay acceptance.

## Evidence carryover and present disposition

Unchanged component evidence remains useful: native binary/source provenance,
material authority, persistence schema, authoring controls and geometry can be
linked as exact unchanged inputs. Preserve their original dates and source IDs.
Do not relabel old full-corpus captures, five-minute sessions, paired predecessor
comparisons or package commands as having executed the new shader. A1's narrow
source proof and actual exact-image results justify a focused delta programme;
they do not erase source identity boundaries.

No new application revision or qualification run is created by this assessment.
Current delivery remains the frozen fd0830ab interactive Optics Lab, with its
real graphical/native evidence, explicit enabled-optics PERFORMANCE HOLD and
Draft/HOLD. A1 is preserved as useful, reproducible follow-up research. Further
implementation should follow completion of the principal delivery and a concrete
capacity/owner-need decision, not an unbounded sequence of late shader variants.
