# Strata 003 qualification registration

Registered before this lane's optical timing or graphical comparison execution.
The source baseline is Strata 002 archive
`410ac8e5e613b1454928699dbc9a68cd035f0894`, whose application is
`934cc0c0eef70dad528155e9a92eebe25e2757eb`. This record defines observations;
it does not claim they have run or passed.

## Source and hardware boundaries

Use the pinned Godot `4.7.stable.official.5b4e0cb0f` for qualification. An
available `4.7.2` runtime may only supply explicitly labelled development
diagnostics. Bind each run to source/tree, local delta, runtime and native/Rapier
digests, driver, display backend, render method, source scene, viewport, camera,
profile settings and observer configuration. Freeze native geometry and pause
visual atmospheric phase for still comparisons. Never infer native authority
from a rendered image or source recipe alone.

Hosted software-rendered callback measurements do not establish physical
Windows 11/NVIDIA responsiveness, displayed GPU FPS or human perceptual success.
Other processes in this shared execution host are a confound; record concurrent
load and prefer interleaved repeat comparisons. A single difference smaller
than host variance is inconclusive.

## Comparative cohort

1. Original Strata 002, unchanged rendering inputs.
2. Strata 003 Classic, with optical processing disabled.
3. Gameplay Clarity.
4. Architectural and Cinematic Deep Focus as balanced alternatives.
5. Optical Lens or Diorama with the most expensive admitted quality/effect path.

All five original substantial environments remain the comparison corpus. A
purpose-built same-material fixture challenges false platforms, decorative
stairs, a blocked-looking physical passage, repeated detail and actor overlap.
The original scene geometry is never rewritten to improve an optical score.

## Engineering gates

- Classic/bypass must preserve exact framebuffer pixels under a paused,
  identical native/camera/atmosphere state. Any difference requires explanation
  and repair before claiming exact reference compatibility.
- World generation, physical epoch, worker, actor session/body identities and
  complete stored-material native readback remain unchanged by optical controls.
  Native simulation is paused for byte-equality checks; separate live trials
  establish progression.
- Presentation control changes add zero decorative native captures and zero
  material texture uploads. They must not trigger native edits, reset or ticks.
- Play camera/picking round trips remain correct for pan, zoom, rotation, Flat,
  Stack and Solo. Optical inspection never changes the authoritative edit plane.
- Actual framebuffer checks cover transparent boundaries, empty planes, alpha
  edge halos, viewport resizing, min/max settings and pixel-preserving bypass.
- Scene admission retains the unchanged **45,000 ms** target. Strata 002's five
  final extracted Windows misses (51,619 / 66,316 / 66,200 / 59,958 / 54,804 ms)
  remain failures of that target, irrespective of successful functional admission.
- Save/reopen restores authored optics; temporary bypass, focus preview and
  inspection plane do not enter authored saves. Malformed or unsupported optical
  state must refuse without replacing the active scene.

Implementation-scope note added after registration: the ordinary Workbench
exposes pan and zoom but no rotated-camera control. The registered camera
rotation case therefore remains unexecuted; actor rotation coverage does not
substitute for it. This limitation must remain visible in the final disposition.

## Comparative performance interpretation

Warm-up precedes each observed sample, and samples retain all intervals including
tails. Register native tick/physical tick deltas, actual elapsed monotonic time,
native and physical progress-interval distributions, callbacks, main-thread
process time, texture uploads, native capture counts and process/RSS information.
Frame callback intervals alone are not physical progression.

For a matched host with repeatable load, a balanced profile is provisionally
non-regressing only if its median native and Rapier progress rates are at least
90% of Classic and physical interval p95 is no more than
`max(1.20 × Classic p95, Classic p95 + 10 ms)`. Inspect p99/max and stalls over
100/250/500/1000 ms separately; the percentile gate cannot hide severe stalls.
Report confidence limits or repeat spread. Low sample counts or unstable hosts
produce **INCONCLUSIVE**, not PASS. These are comparison thresholds for this
research packet, not a replacement for the owner's ordinary playability gate.

Optics-disabled cost must show no optical shader or per-frame optics processing.
The selected architecture must have bounded material/resource counts through
repeated profile switching, scene replacement, disable and teardown. RSS alone
cannot establish GPU residency or memory leaks; include actual resource identity
and count observations.

candidate/predecessor, predecessor/candidate. Each process has isolated user data,

measure. Retain raw process logs, CPU/RSS samples, all step timestamps and native
publications, actual image bytes and all admission misses.

Apply the registered rate/p95 thresholds above to the three independent windows
per source. Report per-window populations and spread. An observed threshold pass
does not make this short hosted observation sustained physical hardware
qualification. Original002 admission targets and physical owner acceptance stay

## Independent perceptual assessment

Compare actual matched application captures and movement sequences. Record
false-platform, passage, actor visibility, architecture retention, tonal depth,
clipping/halo and distraction observations separately. A blinded-order review
may score readability and artistic preference from 1 to 5, with concrete reasons
and an explicit unsure option. Reveal profile names only after initial scoring
where practical. Retain reviewer disagreement and attractive failures.

Automated luminance/edge/detail measurements are supporting evidence. They
cannot prove a person understands which surfaces have collision. Assistance
must identify Play through luminance/visibility structure as well as colour and
must have an immediate reversible exit. Human gameplay acceptance remains open.

## Separate actual motion capture population

The `motion` phase is a separate presentation observation with deliberately
instrumented framebuffer readbacks, never a performance sample. It records ten
actual PNG frames for each of Classic, Gameplay Clarity, Cinematic Deep Focus
and Diorama. It uses three ordinary authored Midge instances on the existing
challenge terrain, explicit existing layer depths0.15/0.4/0.7 and parallax
strength0.65, and the ordinary close240×135 view with pan/zoom to480×270 and back.
These scene variants are recorded in the report; original scene material recipes
and all four World ownership roles remain unchanged. Only the selected actor
receives the existing bounded pilot action. No body pose is injected.

Require at least six further actual completed Rapier steps before each frame,
monotonic actual native/physical ticks, exact saved-image hashes and decoded
image extent, actor/camera/configuration witnesses and accurate Play picking.
Keep all actual step records and native owner identities. Static decorative
material hashes must remain equal; Play hashes may evolve because Sand/Water
and physical interaction run normally. The sequence must not incur decorative
native captures or uploads between its deliberate before/after readbacks.

The offline gallery may replay these original frames at an explicitly arbitrary
inspection cadence. That playback speed is not recorded gameplay FPS, and the
readback-perturbed sequence is not a substitute for sustained interactive owner
play on physical hardware.
