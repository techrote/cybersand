# External complete portable package reader

**Specialist B · 26 November 2026 · source and adverse-control review.** Actual final evaluator qualification is pending at this registration checkpoint. The controls below do not stand in for the shipped ZIP, its native campaign or its ordinary Windows command.

The frozen `tools/package_strata3_workbench.py` verifies both embedded predecessor comparisons. On Linux it inherits the retained Windows command-basename limitation documented in [the portable predecessor annex](b-portable-predecessor-reader.md). The external `tools/ci/strata3_package_portable_verify.py` supplies the already reviewed one-expression predecessor verifier to that unchanged frozen package module in memory. It does not implement a second, reduced package checker.

## Preserved verification boundary

The helper requires the exact clean frozen application `fd0830abcfadd9ae19162e5677943bb131223e59`, tree `fd4dc12d6bfd3e13d6b4d26eede8a1171ca1b499`. The package reader and its imported tool modules are checked directly against that commit's Git blobs. The helper requires the actual inner-ZIP and manifest SHA-256 values, which must come from a separately retained download record. It checks the original ZIP, rejects unsafe or normalized member names, links, case-colliding names and unbounded contents, and extracts into an absent directory outside the frozen source.

It first invokes the original frozen `package.verify(..., pristine=True)`. A successful result is preserved. Only the exact known command-basename refusal can proceed to corrected re-reading; an unrelated original source, runtime, payload, gallery or evidence rejection remains a rejection. For the corrected invocation, only `package.predecessor.verify` is temporarily replaced. The original function is restored in `finally`, including on failure. Every other frozen package gate executes unchanged, including both platform campaigns, original authoring compatibility, native runtime pins, source blobs, licenses and dependencies, generated owner guidance, profile copies and exact gallery reconstruction.

After admission, the helper compares the complete original ZIP member inventory with the extracted files again, rehashes the unchanged archive, and checks the frozen imported module inventory. Its receipt contains the exact ZIP/manifest identities, both reader outcomes, source module hashes, paired adapter identity and the absence of any Godot invocation. The receipt must be outside both the pristine extraction and the frozen source. These are static custody checks; they do not claim a new Windows execution.

## Focused controls and independent review

Ten controls pass before use on the actual package. They cover the exact synthetic container byte roundtrip and absent extraction boundary; wrong ZIP and manifest hashes; unsafe/ambiguous portable paths; raw ZIP NUL/backslash spelling; case collisions and links; loading actual frozen modules; refusal of an unrelated original gate failure; refusal at a later unchanged gate after the path correction; exact agreement when the original reader passes; and refusal to place the output receipt inside either the package or frozen source. Synthetic container fixtures are explicitly not evaluator fixtures.

Specialist A independently inspected the unchanged frozen verifier call, scoped function replacement and restoration, and transitive imports, then repeated the controls. A also independently identified the output-location hazard: a receipt written after verification must not overwrite a previously absent extraction's manifest. The output boundary now refuses that location before any extraction, with a tenth adverse CLI control covering both protected trees. A re-read the repaired boundary and independently repeated all ten controls successfully. No real evaluator was changed during this review.

The source-only registration records exact helper/test hashes and frozen module inputs. A later receipt must supply the actual final artifact identities and result. The original hosted Windows verifier remains authoritative for its unchanged Windows execution; this helper is a separately identified independent Linux re-read.

## Reproduction after the actual ZIP is available

```sh
python3 tools/ci/strata3_package_portable_verify.py \
  --source-repo /path/to/clean-frozen-fd-checkout \
  --archive /path/to/original-inner-evaluator.zip \
  --archive-sha256 ACTUAL_ZIP_SHA256 \
  --manifest-sha256 ACTUAL_MANIFEST_SHA256 \
  --extract-to /path/to/absent-external-extraction \
  --output /path/to/new-external-package-receipt.json
```

Run the helper from its external archive checkout. It deliberately refuses to use an updated evidence-archive branch as the frozen application source. The existing performance HOLD and physical owner acceptance remain unchanged regardless of the static result.
