## Scope and skipped-job semantics

Native/GDE's existing fixed exclusions are workflow files, documentation, `AGENTS.md`, the PR template and the CI-provider checker/tests. A changed path outside that list selects their full validation route. The Ready-transition classifier applies the same rule; a failed classifier cannot make an admitted required aggregate pass through skipped workers.

The separate Native source-scope advisory always emits `native_skip_authorized=false`. No required job consumes an advisory exemption. Unknown, unsafe or ambiguous advisory inputs do not authorize skipping. A future finer source-aware scheduler would require explicit audited ownership and independent review; CI-OPT-002 has not introduced one.

Draft suppresses the expensive routine Native/GDE and scoped Water lanes, but not every feature campaign. Some matching feature-specific workflows execute on Drafts. Main/manual execution and publication keep their existing run identity and concurrency rules. Cancelled, failed, missing or incomplete worker evidence is not a passed test.

These are repository procedural qualification requirements. This report does not claim that a remote branch-protection rule was installed or changed.
