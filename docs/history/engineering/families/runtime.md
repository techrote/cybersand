### RT-CERTIFICATES — Sparse frontiers, transactional models and sleeping proofs

**Primary items:** #554, #555, #556. Findings RT-F20–F21. Protected research.

These studies are valuable partly because they falsify attractive generalizations. B4 packet-stage percentages did not translate to comparable whole-path gains, and samples were publications that can repeat a tick. B2/B5 churn examples were slower without avoiding rule evaluations; same-cell-count geometry restore invalidated a stale roster. B3 models prepare/commit/refuse but does not establish actual native cross-owner momentum/rollback semantics. [#554](https://github.com/techrote/cybersand/pull/554), [#555](https://github.com/techrote/cybersand/pull/555), [#556](https://github.com/techrote/cybersand/pull/556).

One current-source seam is worth preserving as a **conditional test question**. The non-Workbench actor path calls `drain_effects()` (which clears them) and ignores `set_rigid_body_states()`'s returned admission; that function can refuse the batch.
