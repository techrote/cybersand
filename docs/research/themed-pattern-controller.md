# Small-model themed pattern controller

## Where are the compiler, corpus, adapter and gallery?

WB-ART-SLM-001 lives in
[`experiments/wb-art-slm-001/`](../../experiments/wb-art-slm-001/README.md).
Its [bootstrap report](../../experiments/wb-art-slm-001/BOOTSTRAP_REPORT.md)
owns the measured run results and artifact identities. The
[native gallery](../../experiments/wb-art-slm-001/gallery/README.md) is a
self-contained inspectable atlas. The [plan](../../experiments/wb-art-slm-001/PLAN.md)
and [five hourly worker contracts](../../experiments/wb-art-slm-001/AUTOMATIONS.json)
describe continuing development, not simultaneous training jobs.

The twelve initial words are roots, coral, veins, mycelium, strata, dunes,
crystals, honeycomb, labyrinth, ruins, circuitry and ribs. A model predicts a
strict compact JSON program containing generic motif layers, density, scale,
width, angle and layout. The host supplies seed, focus dimensions, material and
work limits. A deterministic compiler emits existing local-coordinate Art shapes.
The current provider transport remains content JSON; a native function-call
envelope is a separately tested future seam. The small model does not obtain
arbitrary code execution or cell authority.

The initial CPU adapter candidate is LiquidAI/LFM2.5-350M. LFM3-1.7B remains the
larger accelerator candidate. Sprocket-500M root Instruct, its distinct Chat
checkpoint, SmolLM2-135M-Instruct and optional 360M have separate pinned profiles.
A profile, downloaded model, training loss or theme metadata field does not
establish model-native control quality. The actual run report distinguishes
executed baselines and adapters from planned candidates.

## What does native qualification establish?

The teacher campaign executed 864 cases and preserved a 192-image gallery on
exact source `90719c72b9fcf90593fb7878354051ad601b47fd`, official Godot
`4.7.stable.official.5b4e0cb0f`, and the matching published Linux native library.
The mounted Art planner/executor changes actual paused native Worlds. Independent
reconstruction of native receipt rows matches stored-cell captures and PNG pixels.
The campaign observed zero out-of-focus writes and unexpected material cells;
protection, Stop and source custody are global gates. Shared Undo/Redo and
save/reopen have explicitly counted representative coverage. The images are
native material-readback visualizations, not desktop screenshots.

This is a pinned **Linux headless native-material pilot**. It does not qualify
current accepted main, Windows, graphical framebuffer presentation, physics
behavior or human artistic acceptance. The experiment branch preserves accepted
main's newer #563 capability consumer; the older Art-bearing pilot source is not
merged over it. Production defaults and existing model aliases remain unchanged.
User Windows launch commands accept an explicit engine path; the confirmed
console path is `C:\Godot_v4.7-stable_win64_console.exe`.

## How do corpus and model claims stay separate?

The synthetic bootstrap has 1,152 train, 192 development and 192 final examples.
Two phrasings share each exact executed target trace. Structural groups use the
actual theme/motif/layout signature, before seed expansion; exact target programs
and normalized prompts cannot cross splits. Primitives are shared, so this is
limited template/layout generalization, not unseen morphology.

Admission binds the exact completion, compiler, host context and expanded
operations to a globally passing native receipt and an inspected representative.
The assistant's visual inspection is provisional: dense coral crowds the bottom,
and narrow border strips compress several motifs. No blind human recognition
rate is claimed. The final set is excluded from model training and development
feedback. Reference-generator renders, raw untuned outputs, accepted adapter
predictions and rejected requests remain distinct.

Strict inference preserves raw output and rejects malformed, duplicate-key,
nonfinite or unterminated JSON. Checkpoints preserve optimizer, scheduler,
scaler, RNG, sample cursor, model/data/template identities and file checksums.
No hosted Actions training, paid compute, production promotion or changes to
NeuroRunner's separately frozen NCR experiments are authorized by this experiment.
