## Owner evaluator and first session

Download the qualified [Windows evaluator artifact](https://github.com/techrote/cybersand/actions/runs/45565621408/artifacts/15001055330),
extract its inner `CyberSand-goblin.zip` to a writable folder, then run

native libraries, Rapier and required runtime files. A separate engine, compiler
or Python installation is unnecessary for the evaluator. The artifact wrapper
and inner evaluator are distinct ZIP files with distinct hashes.

For a first visible experiment, choose **Construction table**, **Builder**, seed
**605**, budget **64** and pacing around **150 ms**. Press Start, inspect the
current intention and animated pointer, then use Discovery to inspect actual
coverage and interesting observations. Pause holds decision dispatch; bounded
Step admits one decision; Stop drains input and pauses the native simulation.
Native time, action count and real elapsed time have separate displays.

Memory export/import/clear controls operate on the marked disposable test
profile. Imported history supplies search hints; it never creates fresh coverage.
Explicit matching-prefix reuse is a separate control. Clearing memory preserves
existing campaign archives. The launcher creates a fresh isolated profile and
can retain bounded memory between launches. The ordinary game remains usable
when goblin is disabled.

The four scrollable tabs are Play, Discovery, Memory and Guide. The laboratory
provides recent actions, an observation queue, replay, bounded reduction and
data-only regression export. A classification chosen in the UI is a triage
record: it cannot promote an observation to a confirmed production defect.
Optional overlays show actually observed trajectories and edit regions.
