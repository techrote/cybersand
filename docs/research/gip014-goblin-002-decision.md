# GIP-014-goblin-002 — owner decision packet

**Draft / HOLD.** The successor supplies an opt-in ordinary Workbench laboratory,
55 typed gameplay operations, 16 policy identities, ten authored scenarios,
observation-based discovery, bounded persistent memory, native game tapes and
automatic reproduction/reduction tools. A self-contained Windows evaluator is
qualified at the exact source below. No novel production gameplay defect has
been established. No merge, Ready promotion, default activation, unfinished
programme integration or physical NVIDIA acceptance is authorized or claimed.

This packet is the compact decision route. The [mission ledger](gip014-goblin-002.md)
retains the complete chronology, failed qualification attempts, infrastructure
interruptions, source corrections and specialist handovers. The
[machine evidence index](../../tools/gip014/decision-index-002.json) records exact
public identities. Later documentation or diagnostic commits do not silently
qualify a different game source.

## Owner evaluator and first session

Download the qualified [Windows evaluator artifact](https://github.com/techrote/cybersand/actions/runs/45550152509/artifacts/14994660661),
extract its inner `CyberSand-goblin-5ee5dffc78d5.zip` to a writable folder, then run
**Open goblin.cmd**. The package contains the actual ordinary Workbench, Godot,
native libraries, Rapier and required runtime files. A separate engine, compiler
or Python installation is unnecessary for the evaluator. The artifact wrapper
and inner evaluator are distinct ZIP files with distinct hashes.

For a first visible experiment, choose **Construction table**, **Builder**, seed
**605**, budget **64** and pacing around **150 ms**. Press Start, inspect the
current intention and animated pointer, then use Discovery to inspect actual
coverage and interesting observations. Pause holds decision dispatch; bounded
Step admits one decision; Stop drains input and pauses the native simulation.
Native time, action count and real elapsed time have separate displays.

Memory export/import/clear controls operate on the marked disposable test
profile. Imported history supplies search hints; it never creates fresh coverage.
Explicit matching-prefix reuse is a separate control. Clearing memory preserves
existing campaign archives. The launcher creates a fresh isolated profile and
can retain bounded memory between launches. The ordinary game remains usable
when goblin is disabled.

The four scrollable tabs are Play, Discovery, Memory and Guide. The laboratory
provides recent actions, an observation queue, replay, bounded reduction and
data-only regression export. A classification chosen in the UI is a triage
record: it cannot promote an observation to a confirmed production defect.
Optional overlays show actually observed trajectories and edit regions.

## Findings and automatic regression capture

No novel production gameplay defect is confirmed. The investigation found and
repaired goblin-side issues and rejected unsupported conclusions. Deliberate
negative controls, legal unusual behaviour, infrastructure failures and
test-oracle defects remain separate classifications.

The strongest captured failure is the historical **Monowheel origin oracle**.
Its actual 44-action tape ended at a completed placement whose cab was 1.5 cells
below the authored origin, exactly as the product catalogue requires. The old
oracle incorrectly compared the cab directly with that origin. An independent
fixed historical run executed the unchanged d849 game and oracle, preserving
the failure instead of applying the correction during reproduction.

It reduced **44 actions to one** through twelve fresh probes of lengths
44, 44, 22, 22, 11, 11, 5, 5, 2, 2, 1 and 1. Every accepted length reproduced
twice under the exact target action, admission, assertion and expected-value
rule. Across those probes, **170 attempted rows = 168 completed actions + two
expected refusals**. Every target placement completed. The construction fixture
and target parameters remain required; one-minimal under action deletion does
not mean globally minimal setup.

The data-only regression bundle includes original/reduced tape, actual fixture,
exact source/provenance, failure contract, material evidence and a constant
ordinary unittest. The reproduction check passed. The unittest correctly failed
on the unchanged historical assertion; there is no claim that an unchanged
product invariant failed before and passed after a production fix. Native
reduction consumed 140.553 seconds, peaked at 781,647,872 sampled bytes, observed
17 owned processes and left no survivors. Lead review passed 1,970 custody and
contract checks; independent delivery review passed 208.

## Boundaries, remaining work and decision

The laboratory remains opt-in and confined to disposable local sessions. Tapes
are capped at 1,024 actions and 32 MiB; coverage maps at 2,048 keys each; a profile
at 64 archived campaigns and 512 MiB; interactive reduction at 128 input actions,
twelve probes and 240 seconds overall. Python reduction has its separately
documented finite probe and wall bounds. Hosted owned processes use PID plus
creation time, sampled process-tree RSS, deadlines, bounded logs and cancellation
receipts. No-survivor evidence applies to the owned observed trees, not a global
machine process audit.

Material coverage describes source-matched local adjacency and edit transforms,
not a verified chemical reaction catalogue. Actor/environment coverage describes
observed model, fixture, zone and control state, not successful navigation or
physical contact. Conservation is checked only in the justified closed
nonreactive Sand experiment. Authored save/reopen and resumable experiment queues
do not restore arbitrary evolved asynchronous physics. Cross-platform physical
trajectories are not expected to be identical.

Source capabilities are broader than the independently qualified combinations.
No universal performance, reliability, behavioural-recognisability or training
claim follows from these campaigns. The final owner decision remains **retain
the qualified evaluator for experimental review and keep PR #781 Draft/HOLD**.
Corrected Linux/memory analysis and the narrow retained-clock diagnostic must be
resolved explicitly before their outcomes are added to this packet.
