## Owner acceptance checklist

Place the newly delivered ZIP, matching `.zip.sha256` sidecar and
`CyberSand-SWARM006-Windows-Owner-Acceptance.ps1` in one folder. Run the launcher
from PowerShell with `-Archive` naming that ZIP and `-Destination` naming a new
empty folder. Add `-VerifyOnly` to verify and extract without starting the app.
The launcher binds the exact archive hash and source; use the accompanying
launcher rather than one from a previous evaluator. It does not install or
replace the ordinary CyberSand application. After extraction, `Open Workbench.cmd`
starts the bundled app with its bundled native generator manifest.

The evaluator opens a synthetic test World unless an owner-authored setup is
explicitly loaded. Keep an original setup copy unchanged before evaluating an
imported owner World. The automatic Windows evidence exercises fresh-process
reopening separately from the owner's own hardware and setup acceptance.

- Verify the ZIP/sidecar/launcher source and open the included Workbench.
- Confirm Recovery defaults OFF and V1/V2/V3 controls still work.
- Generate ON, select Final composition, and inspect Joints, Unresolved,
  Clearance and Revisions. Pick actual native cells; then inspect a provisional
  round and confirm its final-only restrictions.
- Exercise a native-complete construction and a blocked proposal. Preview must
  leave the World unchanged, and only a complete validated proposal may Apply.
- Apply, Undo, regenerate, Apply, Save start, exit and reopen in a fresh process.
  Save start records authored state; it is not a save of evolved simulation.
- Confirm changed World/settings, stale executable identity and altered native
  evidence refuse without mutating the World.
- Record the physical Windows/NVIDIA version, exact binary identities and any
  failures or visual problems. Exact original-owner-world socket repair remains
  a separate reproduction gate if the input is unavailable.
- Retain Draft/HOLD until a subsequent explicit owner acceptance/merge decision.
  Diagnostic rejection granularity remains partial where reasons are combined;
  bounded frontier exhaustion is not proof of global architectural impossibility.
