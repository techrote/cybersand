## Registered discriminator

Existing sums contain attempted directions and clamped density, not actual grain
velocity or parcel identity. Native epoch/state alone is not movement evidence.
S admits a granular blocked attempt only if the source tuple completed native
transport in the immediately preceding tick, its last displacement has positive
dot product with the attempted direction, and that transport witness has not
already supplied a contact. Consume at most once; later real transport can renew
the witness. A continuous stream must supply successive fresh witnesses.

Use optional per-resident-cell uint64 stamps (eight bytes/cell, bounded by existing
chunk capacity), allocated on serialized construction/chunk preparation, never in
the contact hook. Stamp native successful move/swap destinations; invalidate
non-transport writes, painting, conversions and out-of-tick body relocations.
Direction and tick are exact discrete provenance, not physical momentum. Reset
retires history; masks/contact-counter resets must not erase it between ticks.
Stamp range exhaustion must refuse rather than wrap into fresh authority.
Workers use the existing exclusive cellular write domain, no Godot APIs or locks.
Report sidecar capacity and admitted counts; ordinary construction allocates none.
This is transient coupling history, not a new save/replay guarantee; restoring a
World starts without an arrival witness, like fresh body-contact authority.
Temperature-only edits preserve the transported tuple's motion witness; they do
not replace its material/state or create transport. This clarification precedes
all physical candidate captures. The admitted impulse still uses current material.

Retain raw all-attempt J/L and legacy contact_gain0.025. Keep distinct admitted
incoming J/L/counts for all experimental arms. Subtract RAW granular sums from
legacy even in S; otherwise suppressed events leak back through the old path.
C uses raw, E uses none, S uses admitted incoming sums before existing shared-cap
and passive recomputation. No event-gain, friction/load/correction/actuation/mass
change. All arms use the same optional observation provenance. Native admission
requires a new exact experiment token; old C/E behavior stays reproducible.
