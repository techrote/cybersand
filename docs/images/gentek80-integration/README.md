## Refusal and interpretation

![Failure and refusal index](failure-and-rejection-index.png)

Every Gentek receives six common variants including a 1024-square render; eight showcases receive five additional controls. The native campaign retains 240 expected invalid-input refusals. A cardinal component count describes cell contacts in a finite crop, including glazing; it does not establish physical load bearing or player traversal. Thin Rosework tracery includes diagonal one-cell contacts. Ordinary Workbench editing, simulation and save/reopen are qualified separately.
