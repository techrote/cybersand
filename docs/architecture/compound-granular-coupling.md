# Compound granular response and native detachment

## What is composed, and what stays experimental?

The owner authorizes shared coupling reconciliation and detached-object response
qualification. The [registration](../operations/gcr-detachment-integration-plan.md)
precedes candidate execution and owns the frozen laws, mechanical prerequisites,
56-capture maximum and decisions. Fresh maina8f08a67 is reconstructed with selected
source/tests from [detachment#347](https://github.com/techrote/cybersand/pull/347)
and [GCR#348](https://github.com/techrote/cybersand/pull/348). Their earlier evidence
retains its exact source/runtime scope; no combined-source pass follows from it.
The lightweight fleet is not an input. Ordinary defaults remain legacy/B0.

The opt-in detachment session admits one homogeneous ambient Wall/RedBrick
component, at most1024 members in an included resident64x64 domain. It transfers
exact native material/state/temperature tuples into the native aggregate store;
one main-thread Rapier body moves the exact nonoverlapping rectangle union.
The registered fixture has520 members and six shapes with a crown pixel hole
and an AABB concavity. Native unit-square mass/COM/inertia remain authoritative.
No density rescaling, actor controller force, sleep, restoration, generalized
fracture or ordinary-playground expansion is introduced.

## Who owns each transition and response?

Native cells remain authoritative through prepare/ack. Commit transfers exact
payload into the native aggregate, with Rapier inactive while static collision
is retired. Finalize binds the native token, body generation and physics epoch.
The session awaits an explicit copied acknowledgement of the successfully
installed complete compound mask before unfreezing. Matching mailbox length is
not an occupancy acknowledgement. Failed priming/quarantine holds both clocks;
inactive rollback and whole-session reset retain their original witnesses.
Every await checks generation and the exact worker instance. Sleeping does not
return payload ownership to cells.

Only the existing asynchronous native owner reads/writes World. Immutable copied
geometry/lease values cross the worker boundary. The existing Rapier bridge
alone applies a body wrench on main. Granular legacy reactions are suppressed
when GCR owns them; non-granular response remains one bounded compatibility
channel. Four-parcel conservative displacement remains a native material operation
with capacity, geometry, mask, residency, state and thermal preflight. It is not
an accepted bulk penetration solution and never adds one reaction per shifted
parcel. Native failure stops preparation before later effects/emissions/ticks.

## What does the compound value interface mean?

`prepare_gcr_compound_coupling(states17, lease, resolve_overlaps)` receives at most
64 geometry records. Proxy IDs remain distinct for occupancy and material
operations. Common repeated fields are physical COM velocity, omega, actual
aggregate mass/inertia/COM, friction, dt, sample and session; proxy point velocity
must not replace COM velocity. The copied lease echoes token/body_id/
body_generation/physics_epoch and must match the active native snapshot.
Incomplete membership, malformed/mixed metadata and stale leases refuse before
mutation. The existing independent17/14 and legacy11/9 interfaces remain separate.

`gcr_compound_results()` returns exactly one14-value record, version2 and physical
ID1. It contains net J, moment L about sampled COM, one correction and source
counts. Version1 independent consumers reject it. The compound consumer checks
session/sample/epoch, duplicate/age<=1 and maximum movement<=0.5 for every actual
proxy corner, then translates L to current COM including correction and scales
J/L together by the existing age factor. Main applies one central J and one
torque L. It does not add proxy lever arms again or apply legacy cap3 to GCR.
Correction and opposing-velocity zeroing retain separate accounting.

## How are geometry, capacity and work bounded?

Each rectangle retains eight source bins and at most16 quadrature nodes; distinct
planes and gaps are never collapsed into an AABB or eight aggregate bins. At most
1024 nodes enter one four-pass solve using one provisional physical velocity,
one event-first normal/passive capacity20, globally normalized unique-source
weights and one passive-energy guard. At most8192 scalar axis updates occur per
boundary, matching the earlier64-body ceiling. Scratch size/capacity is explicit
in source diagnostics and registration: the fixed solver workspace occupies
73,728 bytes, plus bounded pointer/shape stack storage. This is a solver bound,
not a claim that the adapter, copied arrays/dictionaries or all World mask
maintenance are allocation-free. Mu, per-source2 capacity, material policy
and response equations are not tuned by composition.

Unique source and physical ownership are separate from geometry proxy IDs.
Sibling seams cannot count a source twice or manufacture extra capacity. Events
sum their force/moment before one budget charge; non-granular compatibility shares
one norm-based legacy3 scale and proxy-centred moment. Area-weighted correction
is bounded0.5 once for the physical body. No new pressure or friction owner exists.

Malformed input refuses before mask or material mutation. Angle admission checks
the host scalar range before conversion and requires finite derived geometry.
Unexpected exceptions during compound mask preparation invalidate the response
and quarantine native World and its active aggregate, retaining the actual
payload/cell/mask state for inspection and whole-session recovery. The failure
path does not attempt an implicit restore. Testing the explicit native quarantine
with allocation forbidden is separate from fault-injecting the adapter catch;
the latter requires its own evidence before being described as executed.

At mass520 and fixture gravity92.12, maximum normal20 per fresh60Hz response is
small relative to gravity impulse798.373. Qualifying protocol/ownership does not
establish credible support or impact resistance. Report dense penetration,
correction, passivity, hard contact, async delivery and unresolved measurements
separately. Preserve known R2/A1 failures; do not make the structure lighter or
retune the law to pass this registration.
